# Luma CMS v0.0.25-rc.12 — Multilingual setup wizard

## Highlights

- Setup wizard supports ~130 WordPress locales with browser/region detection and explicit language selector on the welcome step.
- Requirements and setup API errors return stable `message_key` / `message_params` for client-side translation.
- Optional **Allow weak password** checkbox on the owner step (`allow_weak_password` on finish API).
